# The Class — Perfume E-commerce Website

The Class is a modern e-commerce website for a perfume brand, designed to provide customers with an easy way to explore and purchase perfumes online.

The project focuses on creating a responsive shopping experience with product browsing, categories, product details and a structured e-commerce interface.

## ✨ Features

- 🏠 Responsive home page
- 🧴 Perfume product listings
- 🔎 Product browsing and categories
- 🛍️ Product detail pages
- 🛒 Shopping cart functionality
- ❤️ Product saving/favorites
- 📱 Responsive design for different screen sizes
- 📖 Brand and product information
- 📩 Customer contact/enquiry options

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Supabase
- PostgreSQL

## 📂 Website Sections

- **Home** — Introduction to The Class and featured perfumes
- **Shop** — Browse available perfumes
- **Product Details** — View individual perfume information
- **Categories** — Explore perfumes based on different categories
- **Best Sellers** — Highlights popular products
- **About** — Information about the brand
- **Cart** — Manage selected products before purchase
- **Contact** — Customer enquiry and contact information

## 🗄️ Database

The project uses Supabase/PostgreSQL to manage product information.

Product data includes information such as:

- Product name
- Category
- Description
- Price
- Product image
- Featured status
- Best-seller status

## 🚀 Planned Features

The project is being further developed with additional e-commerce and customer automation features.

Planned improvements include:

- 💳 Payment gateway integration

- 📦 Order processing and management

- 👤 Customer account and order history
- 🔗 Integration between the website, database and WhatsApp automation

## 🎯 Project Purpose

The goal of The Class is to create a complete digital shopping experience for a perfume brand while gradually integrating e-commerce, database management and customer communication automation.

The project also explores how a website can be connected with automation tools to improve customer interaction and streamline the purchasing process.
